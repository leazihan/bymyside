# 平台与自动化说明

bymyside 面向支持项目资料与定时任务的 AI 办公 agent；
## 初始化由助手承担

用户在项目中发送初始化请求后，助手按 `START_HERE.md` 读取资料、引导导入日程、创建记录，并使用宿主平台的工具配置自动化。`automations/` 提供三项流程的执行提示；实际调度和结果通知由所在平台提供。

平台具备可调用的任务创建工具时，助手直接配置；平台要求用户确认时，只把最后的确认步骤交给用户。仅生成提示词、写入一份配置草案或调用失败，都不能算创建成功。

## 选择平台时检查什么

| 能力 | 用途 |
|---|---|
| 保存并读取多份项目规则 | 让后续会话和定时任务遵循同一套陪伴方式 |
| 持久读写同一份记录 | 记得方向、日程、想法与进展 |
| 当前日期、用户时区 | 按实际时间安排，处理重复日程与例外 |
| 定时执行并访问项目资料 | 自动准备每日/周内容；独立定时会话也必须读到记录 |
| 任务创建与查询工具 | 助手配置、复用与检查自动化，避免重复创建 |
| 结果通知或授权消息渠道 | 把自动运行结果送到用户选择的位置 |

支持文件格式取决于平台的解析能力。日历连接、截图读取和其他办公软件连接器按实际可用能力使用。没有连接器时可导入文件或文字，不因此宣称已同步外部日历。

## 现有平台资料

- [WorkBuddy 自动化说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)：支持周期性任务与指定工作空间；实际创建方式和权限由客户端决定。
- [Claude / Cowork 定时任务说明](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)：支持描述任务与频率后创建，平台可能要求点击确认。其云端和本地文件访问方式需要分别核对。

以上只是宿主官方能力资料，不是本项目已完成兼容验收的名单。作者的日常自动流程已有个人实践；公开版仍需新用户验证。具体版本、账号权限和云端/本地任务可能影响能力，初始化时必须实际检查。

## 运行与恢复

晨间、晚间、周流程共享 `.bymyside/memory/`；定时任务标识和配置结果记在 `MEMORY.md`。使用宿主结果通知时遵循其成功状态；外接消息渠道需有可靠发送回执，成功后才写发送状态。同周期重跑先查发送记录，避免重复通知。

涉及本地文件时，任务必须能访问对应设备和目录；是否需要客户端/设备在线取决于平台。网络或调度恢复后按当前时点接续，不把错过的每条提醒全补发。迁移平台先暂停旧任务，避免两套提醒同时运行。

## 可选历史维护

规划和自动陪伴本身不要求 Python。具备 Python 3 与文件权限时，助手按 `skill/memory-protocol.md` 复核旧日志并运行归档工具；不具备时保留原文并跳过自动归档。
