# 开始使用

## 1. 下载并打开

在 GitHub 项目页面点击 **Code → Download ZIP**。下载后解压，用你常用的 AI 办公助手打开解压后的文件夹；如果使用“新建项目”，将这个文件夹选为项目位置。请确认文件夹中能找到 `START_HERE.md`。

如果助手支持接收并解压 ZIP，可以直接上传压缩包并告诉它：“请解压到一个新的 bymyside 项目文件夹，读取里面的 START_HERE.md 并初始化。” 后续定时任务必须能访问解压后的资料，不能只读取一次附件。

发送：

```text
请读取 START_HERE.md，帮我配置 bymyside。
先检查你能否保存项目资料、设置并运行定时任务，
再引导我导入个人日程，记录当前目标和事项，
配置晨间规划、晚间复盘和每周回顾。
请和我确认时区、运行时间及结果接收位置。
```

## 2. 导入个人日程

先给它一份个人日程：可以是日历导出文件、表格、文档或截图，也可以授权连接日历，或直接描述“工作日九点到六点上班，周三晚上上课”。不需要先重新制作日程表。

助手会整理工作、会议、课程、通勤和其他固定安排，和你确认模糊的时间、重复规则与例外。你也可以告诉它想保护的休息时间，以及最近在意的一件事。

没有完整日程、没有明确长期目标，都可以先开始。未提供的时间标未知，不当作整天空闲；之后随时补充。

## 3. 配置自动任务

和助手确认时区、晨间时间、晚间时间、每周回顾时间，以及在哪里查看消息。随后由它使用平台提供的自动化工具创建三项任务，检查它们是否指向同一份项目资料，并给你一张简短的配置结果。

如果平台要求你点击“确认”或“保存”，完成这一步即可。无法自动创建时，它应准备好三项配置并指出剩下的操作，不让你从头编写提示词，也不能说成已经配置成功。

完成后，助手会生成第一份近期安排，后续按约定自动运行晨间规划、晚间复盘和每周回顾。日常可以随时补充想法与进展。

---

**没收到提醒？** 让助手检查任务是否真正创建、时区与接收位置是否正确，以及平台是否需要客户端在线。网络恢复后从当前时间接续，不要求你补做过去几天的打卡。

**换了助手？** 带走规则和自己的 `.bymyside/` 项目资料，在新平台重新读取并配置自动化；不要让新旧两套提醒同时运行。

更多平台能力与运行条件见 [平台与自动化说明](compatibility.md)。
