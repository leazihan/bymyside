## 必须通过

- [ ] 能在项目中发送初始化请求，由助手读取规则并建立私人记录。
- [ ] 没有明确长期目标也能开始，不被迫填完整问卷。
- [ ] 混合输入能分流，记录想法不等于承诺执行。
- [ ] 明确责任进入现实可行的安排，长期关联不靠系统编造。
- [ ] 卡住时得到可启动的小步，剩余工作与期限仍在。
- [ ] 反馈一个变化后，相关台账与周/日安排一致更新。
- [ ] 新会话能重新读取正确状态，不依赖原聊天。
- [ ] 无反馈标未知；重要取舍由用户决定。
- [ ] 仓库没有新增个人资料或凭据。

## 自动陪伴验收（正式体验必须通过）

- [ ] 助手引导导入个人日程，核对重复规则、例外与休息时间。
- [ ] 助手通过宿主工具配置三项任务，或准确指出平台需要的最后确认。
- [ ] 初始化重跑不重复创建自动化。
- [ ] 晨间、晚间与每周任务均实际按用户时区触发，读写同一份项目资料。
- [ ] 授权渠道收到消息，有可靠发送结果。
- [ ] 同周期重跑不会重复发送；发送失败不会记成功。
- [ ] 延迟执行不补发过期安排。

## 结果
