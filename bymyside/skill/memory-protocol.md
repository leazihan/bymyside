# 保存、清理与运行一致性

## 只维护决策需要的信息

事实归属见 life-model.md。各流程复用同一份当前资料，不分别维护自己的生活模型。旧 outputs、归档、自动化备忘是历史证据，不是当前指令。默认只读取当前方向、台账、周/日安排及本次相关约束；禁止为日常规划递归加载整个 memory、outputs、tmp 或压缩历史包。需要追溯时按具体问题检索资料。

日常只改发生变化的字段，查重后更新原条目。来源指向已存在的资料，不复制私人日记内容进推送或报告。普通互动不强制记录模式、实验或心理解释。普通待办只写必要台账/排期信息，不生成 interview-review、作品集底稿、笔记模板等专项成果文件。日常临时状态只放当天记录；life-map 不承接执行流水。

## 更新必须形成闭环

确认完成、取消或变化时：更新 projects.md 对象；只有影响整体方向或阶段里程碑才更新 life-map；移除或调整受影响周/日时间块；检查依赖解锁与剩余工作；重要结果留下交付位置。
完成项目离开活跃表，简记结果即可。普通任务在当日记录标完成，不另写多份总结。新事件一般直接更新对象，不为每次变化建立事件库。

修改当前资料采用替换有效字段，不把初稿和四轮补正堆在同一活跃段中。矛盾信息标注待核，不能同时按两个版本规划。
移出活跃视图前把确认结果记入当日日志，重要成果保留位置；归档工具保存原文并校验后才移除原文件。确认有效约束、来源引用、未完成责任及用户要求仍存在。不能用行数上限删掉必要信息。

## 清理与归档的实际入口

| 时点 | 动作 | 写回位置 |
|---|---|---|
| 用户确认完成/取消/变化 | 当场更新状态、移出活跃安排、处理依赖 | projects.md、受影响周/日安排；结果简记在当日日志 |
| 每晚收尾 | 补查当日已确认完成/失效项，去重，清除当天生成的无用缓存 | 仍未知的事项保留，不增加未完成计数 |
| 每周复盘收尾或周一兜底 | 同步未完成责任、有效约束、待复核想法；检查旧日志归档资格 | 当前对象吸收必要信息后，旧记录才可归档 |

不新增一个维护定时任务。清理依附既有更新、晚间和周流程，通常无须用户参与。

不具备 Python 3 或必要文件权限时，跳过自动归档并保留原文，记录维护待处理；不得宣称归档成功。规划与复盘仍可继续。

### 文件归档工具

工具：[scripts/archive_history.py](scripts/archive_history.py)。只扫描日期日志与指定类型的旧过程报告；不扫描 life-map、台账、日程表、配置、私人日记原件或既有压缩包。

周收尾先运行预览，查看可归档项及 needs_review；逐项确认旧记录的重要事实、未完成责任、来源和必要证据已进入当前对象或需保留的资料。然后仅在该记录开头写入：

```yaml
---
archive_ready: true
---
```

该标记由系统复核后写入，用户不需要整理。没有复核标记的旧文件不会被工具移走，即使日期已过。

运行方式（工作区根目录；日期替换为用户当地当日）：

```text
python3 skill/scripts/archive_history.py --workspace . --today YYYY-MM-DD
python3 skill/scripts/archive_history.py --workspace . --today YYYY-MM-DD --apply
```

默认保留近七天日志，可按实际检索需要调整。工具生成恢复包与清单，校验包内原文及源文件未变化后才移除原文件；校验失败保留原文件，无可归档项不创建空包。历史包不定期永久删除，避免无依据丢失原始资料。
生成的临时推送文件/抓取副本在成功消费后删除；不删除原始日记或交付物。脚本故障留一条系统侧记录，不能宣称清理成功。

新运行不写长篇自检或完整推理。特殊故障才保存简短诊断，解决后进入历史。自动化 memory 仅保留最近成功发送周期/日期、消息标识、防重复键、运行故障；不存另一套计划或行为限制。下一次成功发送后更新旧标识，不累积全量发送史。

## 可靠执行

运行前读取本次当前资料；保存前若资料已被另一流程更新，重新读变化并合并，避免覆盖新事实。文件写入使用临时文件与替换；重复执行不得重复增加事项。
晨间、晚间、周流程共享对象而非彼此复制输出，计划变更只修改受影响部分。
推送成功之后才记发送成功；失败保留未发送状态。相同周期与内容已成功发送就跳过。改计划不等于新增推送，风险通知依 daily.md。
调度延迟时以实际时点规划，过期时间块作废但事项仍需检查；旧晚间和当前晨间冲突时合并必要信息，不补发整套过期流程。
晚间延迟到次日、且同日晨间已成功发送时：晚间只发前一日复盘与阻碍，不重复次日安排；已误发的重复内容原地修正（保留发送标识），不追加新通知。发送前先查同日另一条是否已送达，避免同频相撞。

## 反馈未知

先利用已有日记和互动。连续两天没有有效进展信息，在下一次常规推送中集中确认一次；仍未回复就标未知，不连续追问，不推断执行失败。真实风险按事实提醒。
用户暂停某类提醒时停止该类；已由用户授权的固定晨晚约定不会因一次未回复自动撤销。
